Unlimited lookups, metered skips. The two meters in the app bar make the model obvious: browse/analyze all day free-flowing; the only thing that draws down is revealing a skip-traced owner (250/mo included, then overage).
Stack signals, then export. Filter rail combines market + distress type + equity + days-to-auction + draw-area. The result set exports to CSV (Pro-only) so the user can work the list or push to their own CRM.
Deal Analyzer, not a deal-maker. Shows ARV/value + equity math only. No suggested-offer number — that judgment stays with the investor (and routes serious deals to AHR’s office).
Saved-search alerts. “Save this search + alert me” is the retention hook — new pre-auction leads matching the filter fire a push notification (see mobile view).

Mobile “Field / DFD” — work the street, driving for dollars

Map-first, GPS-anchored. Park in front of a distressed house, tap the pin, see equity + distress instantly, reveal the owner, and drop it on a route. Same data engine, thumb-first layout.

Field ≠ office. Mobile is intentionally lean: map, tap-card, route, alerts. No results table or bulk CSV — that’s the desktop war room’s job. Same engine, different face.
Skip meter travels with you. The “95/250 skips” count shows on the reveal button in the field, so a user always knows where they stand before spending a credit.
DFD is the hook. Ted’s key selling point — pre-auction/distressed + driving-for-dollars — is the entire mobile spine: locate, qualify, contact, route.
Push = retention. Alerts turn a one-time lookup tool into a daily habit, which is what earns the renewal after the founding discount tapers.
