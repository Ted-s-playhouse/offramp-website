What’s in the demo app

  • Accounts & login — email/password with secure hashed passwords + signed sessions. Google & Apple buttons are wired into the flow (currently a demo stub — real OAuth is a config flip, see below).
  • Market search — live query against our real lead database. Filter by state (AZ, UT, ID, MT, WY), city, foreclosure status, and minimum equity.
  • Map — interactive pins for geocoded leads (UT/ID/MT today).
  • Deal room — per-property value, loan balance, equity $ and %, beds/baths/sqft/year, occupancy, county, auction date, days-to-auction, trustee file #, foreclosing attorney.
  • Deal Analyzer — live MAO (70% rule), estimated profit, ROI, and a green/red verdict as you type an offer.
  • Skip-trace reveal (Pro) — one click pulls owner mobile numbers (DNC-flagged) + emails, metered against a monthly allowance, mobile-only.
  • CSV export (Pro) — export the current filtered result set.
  • Free vs Pro gating — Free sees deals + equity but owner contact, skip-trace, and export are locked behind Pro.
  • Address lookup — type any address to pull a fresh property/equity report (metered), cached so we never pay twice for the same address.

The path to public launch

Phase 1 — Demo & QA We are here

  • You + your two partners walk the app on staging and list what to change.
  • I fix UI/UX + data issues from your feedback.
  • Decision: confirm launch markets and Free/Pro limits.

Phase 2 — Billing go-live ~1 day once you activate Stripe

  • You: finish Stripe account activation (business info, bank account, tax ID) under AHR LLC.
  • Me: regenerate products/prices/promo codes with the LIVE keys and wire signup → plan → Stripe checkout + usage metering.
  • Test the full purchase with a real card, then a refund, to confirm the loop.

Phase 3 — Legal finalize parallel

  • Terms, Privacy, and Refund drafts are on the site under AHR LLC.
  • You/attorney: review + approve before charging real cards. Key clauses already in: not-a-consumer-report / no-FCRA-use, TCPA/DNC outreach duties, no-resale/scraping, Utah governing law.

Phase 4 — Production hardening 1–3 weeks

  • Real Google & Apple OAuth (needs client IDs / Apple developer setup) — today the buttons use a demo stub.
  • Saved-search alerts (email when new matches hit your market).
  • Geocode AZ + backfill missing coordinates so every market shows on the map.
  • Password reset, email verification, rate-limiting, audit logging, backups.
  • Move the app to its own hardened service (currently sharing the marketing host).

Phase 5 — Launch inventory market-dependent

  • AZ, UT, ID, MT, WY have live inventory now.
  • If we launch CO as a headline market, it currently has zero rows — we’d need to point the ingest at Colorado first.
  • Refresh cadence: confirm how often each market’s foreclosure feed updates.

What only you can do

1. Stripe activation — ~10 min: business/bank/tax under AHR LLC so we can accept real money.
2. Legal sign-off — you/your attorney approve the Terms/Privacy/Refund drafts.
3. Launch-market call — confirm the market list (and whether CO is in v1, since it needs inventory).
4. Google/Apple OAuth — approve creating the developer app entries (I’ll do the wiring).

Honest caveats in the demo

SSO is a stub. The Google/Apple buttons log you into a demo account so the flow is complete; real OAuth is a config flip once client IDs exist.
Map gaps. AZ leads aren’t geocoded yet, so the AZ map is sparse (the list still works). UT/ID/MT show pins.
Data quality varies by row. Equity/value come from our enrichment sources and some rows are thin — the Analyzer lets you override ARV/rehab/offer per deal.
Data licensing. You’ve confirmed our API terms allow third-party use/redistribution — noted as cleared; worth a one-line written confirmation from the provider for the file.
