What stops it recurring

  1. One address key per row (crm.addr_key): house number + USPS-normalised street words + unit + state + zip. "Green Meadow Drive" and "Green Meadow Dr" are one key; "# 5d" and "# 2h" are two. Set by trigger on every insert/update.
  2. Unique index hit_list_addr_key_uniq on active rows: a second active row with the same key is rejected by Postgres, not by convention.
  3. Ingest matches on the key first (then APN + county, then the loose key with the same gates) and drops incoming rows with no house number or no city/zip before they land.
  4. City shear repair: a city like "Peak Three Forks" whose tail is a known city puts the leading words back on the street (zip-guarded so "Lake St Louis" stays a city).
  5. This page regenerates after every feed run; a FAIL exits non-zero and the cron refuses to continue.
