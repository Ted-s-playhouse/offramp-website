NOTE

Two surfaces, not one

"The app" and "the website" are different surfaces with different jobs and different design passes - Phase 3 covers both, separately:

  • The website (offramprei.com, public) - marketing, pricing, the state-by-state legal/rules page, sign-up. Job: convert a visitor into a free or founding account. Static-file site, edits go live on save.
  • The app (offramprei.com/app/, logged-in) - the actual deal room: browse, map, lookup, account. Job: keep a subscriber working real deals day to day.
On staging: right now offramp-staging.americahomerestoration.com and offramprei.com are the SAME running code on the SAME server process - not a real staging/prod split. Any edit goes live on both instantly. Fine for backend work; risky for a big visual redesign while real paying subscribers are on it. Before the Phase 3 UI pass, worth standing up a genuinely separate staging copy (its own process/port) to preview changes before they hit real customers.
