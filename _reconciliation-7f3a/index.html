Bottom line

What already exists (don't rebuild):
  • Foreclosure data + JIT skip trace / property enrichment — both apps
  • The 5-tab field-app shell (📞 Calls · 📋 Leads · 💵 Buyers · 🗺️ Map · ⋯ More), statuses, follow-ups, notes, SMS, GPS map, buyers universe — CRM
  • Credit metering + paywall + deal analyzer + CSV export — OffRamp
  • Google SSO + org row-security foundation + assigned_to plumbing — CRM
What's missing to hit DealMachine-class + your JIT edge:
  • D4D field capture — route/breadcrumb tracking, tap-to-pin a new house, on-device photo capture, offline sync (neither app)
  • Team lead-allocation UI — the manager desktop view to hand foreclosure leads to reps (data plumbing exists, screen doesn't)
  • One unified paywall — merge CRM (free) onto OffRamp's JIT/credit model
  • National scrape + daily refresh — expand beyond 5 states, wire the cron
  • OffRamp lacks the 5-tab shell — port the CRM tab experience so OffRamp = desktop structure + mobile field app
  • Dispo matching + Stripe billing — later phases
Recommended framing: the CRM (revive-buyers-app) is already ~70% of the field app you described — it has the tabs, map, GPS, statuses, SMS, buyers. OffRamp has the money layer (credits, paywall, analyzer, export). The build is a merge, not two rebuilds: put OffRamp's credit/paywall engine under the CRM's field-app shell, then add the 4 true D4D capture features + the team allocation screen.
